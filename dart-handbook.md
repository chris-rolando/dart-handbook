# Fundamentos

## ¿Que es Dart?
- 🚀 Es un lenguaje de programación moderno, desarrollado por Google, que se utiliza para construir aplicaciones web, móviles y de escritorio.

🦖 Tomar como referencia JS.

### Características:

- 🔑 De propósito general: principalmente apps móviles.
- 🔑 Orientado a objetos: 🦖 todo en Dart es un objeto.
- Compilado.
- Versátil: para móviles (Flutter), web y escritorio.
- Programación asíncrona: Maneja tareas simultáneas eficientemente.
- Gestión de memoria automática: Recolector de basura incorporado.
- Tipado fuerte.

## ¿Cuando usar Dart?
- 👑 Desarrollo de aplicaciones móviles con Flutter.
    - Para desarrollar apps multiplataforma.
    - 🦖 Cuando se necesite rendimiento.

# 2. Crear el proyecto 

**Requisitos previos:**
- SDK de Dart.
- Extensión Dart: soporte para Dart en VS Code.
- Extensión Flutter: soporte para desarrollar aplicaciones móviles.

## 1. Usando la paleta de comandos:
- Abre la paleta de comandos presionando Ctrl + Shift + P.
- Escribe `"Dart: New Project"` y continua el asistente.

## 2. Usando la terminal:
- Abrir la terminal.
```bash 
dart create nombre_del_proyecto
```

## 3. Estructura del proyecto:
- El archivo principal es main.dart.

## 4. Ejecuta tu proyecto:
- Abre el archivo main.dart y ejecuta:
```bash
dart run
```
